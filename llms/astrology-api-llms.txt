# AstrologyAPI

> AstrologyAPI is a developer-first astrology platform providing 300+ REST API endpoints for birth charts, Kundli, horoscopes, transits, AI readings, PDF reports, and more. Trusted by 3,000+ products across 50+ countries, including Snap, Bumble, Shaadi.com, AstroTalk, and MSN. Handles 100M+ daily API calls with 99.99% uptime SLA.

AstrologyAPI gives developers production-grade astrology engines under a single API key — covering both Vedic (Jyotish) and Western traditions. It supports AI-powered chat grounded in real birth chart data, MCP server integration for LLMs, on-demand PDF report generation, and multi-language horoscope content feeds. The platform is built for entrepreneurs, developers, and businesses who want to integrate astrological features into their apps and websites — faster, more accurately, and at scale.

Authentication uses HTTP Basic Auth with a single API key across all 300+ endpoints: `Authorization: Basic base64(userId:apiKey)`. Pricing is pay-as-you-go (wallet top-up, no monthly commitments). New accounts get 150 free credits with no credit card required.

## Key Facts (citable)

- AstrologyAPI is a developer API platform (REST/JSON), not a consumer horoscope app. In production since 2013.
- Both traditions are first-class: Vedic (sidereal, with nakshatras, dashas, KP sub-lords) and Western (tropical, with houses, aspects, transits).
- The `ayanamsha` endpoint returns six named systems computed for any birth moment: LAHIRI, KP, YUKTESHWAR, RAMAN, JN_BHASIN, FAGAN_BRADLEY.
- The `planets` endpoint returns, per planet: degree, sign, sign lord, nakshatra, nakshatra lord, pada, house, retrograde flag, and awastha in a single response.
- Documented house systems on Western endpoints include placidus (default), koch, topocentric, poryphry, equal_house, and whole_sign.
- The Palmistry API accepts a palm photo as a public URL or base64 data URL (jpeg/jpg/png/webp, up to 5MB) and returns structured analysis via a palm id.
- The PDF Reports API returns a hosted download URL (`pdf_url`) for white-labeled reports.
- The API is designed for server-side calls (no CORS headers on json.astrologyapi.com); browser-facing apps route requests through their own backend, or use the Access Token method.
- "Astro AI" is the AI product family: the Chat API is a hosted conversational product; the MCP server exposes astrology tools to LLM agents and IDEs.
